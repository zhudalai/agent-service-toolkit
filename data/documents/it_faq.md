# IT 支持常见问题 (FAQ)

## 账户与访问

### 如何创建新员工账号？
1. 提交 IT 服务申请单（ServiceNow → IT → 新员工账号）
2. 需要提供：姓名、工号、部门、职位、入职日期
3. IT 部门会在 1 个工作日内完成账号创建
4. 账号信息会通过邮件发送到直属上级

### 忘记密码怎么办？
1. 访问 https://password.acmetech.internal
2. 点击"忘记密码"
3. 输入工号和注册邮箱
4. 按照邮件提示重置密码
5. 如果邮箱也无法访问，请联系 IT 支持：ext. 2200

### VPN 连接问题
- 确保使用公司提供的 Cisco AnyConnect 客户端
- 服务器地址：vpn.acmetech.internal
- 使用域账号登录（格式：ACME\工号）
- 如仍无法连接，尝试重启客户端或清除缓存

## 设备问题

### 如何申请设备维修？
1. 在 ServiceNow 提交设备维修申请
2. 描述故障现象（附截图更佳）
3. IT 工程师会在 4 小时内响应
4. 硬件故障会提供备用设备

### 显示器申请
- 开发岗位默认配备 1 台外接显示器
- 可申请第 2 台，需直属上级审批
- 支持的型号：Dell U2723QE、LG 27UP850

## 软件与工具

### 如何安装新软件？
1. 优先使用公司软件库（ServiceNow → 软件申请）
2. 不在软件库中的工具需提交审批申请
3. IT 部门会在 2 个工作日内完成评估
4. 涉及安全风险的软件可能需要额外审批

### GitLab 使用规范
- 所有项目代码必须存放在公司 GitLab（gitlab.acmetech.internal）
- 禁止将公司代码推送到外部 Git 服务
- 分支命名规范：feature/工号-描述、bugfix/工号-描述
- MR 需要至少 1 人 Code Review

### 数据备份
- 项目代码：GitLab 自动备份，每日凌晨 2:00
- 数据库：PostgreSQL 每日全量备份 + 实时 WAL 归档
- 文档：Notion/Confluence 每周备份
- 本地文件建议使用 OneDrive 同步

## 安全

### 发现安全漏洞怎么办？
1. 不要公开讨论或利用该漏洞
2. 立即发送邮件至 security@acmetech.internal
3. 抄送直属上级和安全团队
4. 严重漏洞可拨打安全热线：ext. 9999

### 钓鱼邮件处理
- 不要点击可疑链接或附件
- 将邮件转发至 phishing@acmetech.internal
- 删除原始邮件
- 如果已点击链接，立即联系 IT 支持
